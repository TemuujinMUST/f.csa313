## Хэсэг E: Дүгнэлт (debrief)

| Аялал | Олдсон согог |

| Saboteur | BUG-16 буруу JSON-д 200 OK; BUG-01, BUG-05, хайлтын согогийг API түвшинд баталгаажуулсан (bug-17, bug-18, bug-19) |

Хамгийн үр дүнтэй нь Supermodel аялал байсан: функцийг орхиж зөвхөн харагдах байдлыг удаан ажигласнаар 24 минутад дөрвөн өөр согог олдсон. Fed-Ex аялал өгөгдлийн дүрмийн гурван согог (давхардал, буруу он, том/жижиг үсэгтэй хайлт) олсон бол Couch Potato эхний 8 минутад л заавал талбарын validation огт ажилладаггүйг илрүүлсэн. Saboteur аялал хамгийн богино (7 мин) байсан ч UI-аас харагдахгүй BUG-16-г олж, UI-д олдсон согогуудыг API түвшинд давтагддагийг curl-ээр баталсан. Charter-аас гадуур санамсаргүй олдсон зүйл нь оны харагдах формат (1,971) ба буруу он оруулахад «NaN» гарах явдал байсан, учир нь charter-т зөвхөн оны хязгаарыг шалгахаар төлөвлөж, хүснэгтэд яаж харагдахыг тусгаагүй байв. Мөн «Нийт ном» тоолуурыг Fed-Ex-ээр шалгахаар төлөвлөсөн боловч Supermodel-ийн үеэр хүснэгттэй харьцуулж байхад түрүүлж олдсон. Шалгагдаагүй үлдсэн нь HTML ба тусгай тэмдэгттэй оролт (`<b>`, `&`, emoji), curl-ээр байхгүй эсвэл буруу id-тай DELETE хүсэлт илгээх, товчийг дараалан олон дарах, гар (Tab, Enter) ашигласан accessibility, өөр браузер дахь харагдах байдал юм, тиймээс дараагийн session-ий charter нь Antisocial, Rained-Out ба Supermodel (accessibility) аялалаар эдгээрийг судлах байна. Лаб 1-ийн Playwright шиг автомат тест нь BUG-01 (алдааны мессеж гараагүй), BUG-05 (мөрийн тоо ба тоолуурыг харьцуулах), давхардал, буруу он, хайлтын согог, 500 буцаадаг линкийг баригдах байсан, харин тэдгээрийг шалгах assertion-ыг хэн нэгэн урьдчилан бичсэн тохиолдолд л. BUG-16 нь API тест (Лаб 5-ын Postman/Newman) эсвэл Playwright-ийн request API-аар хялбар баригдана. Харин Устгах товчны ногоон өнгө, товчнуудын өнгө жигд бус байдал, оны таслалтай формат зэргийг хүний нүд шууд анзаардаг, учир нь эдгээрийг автомат тест зөвхөн яг тэр CSS эсвэл текстийг шалгахаар бичсэн үед л барина. Эндээс автомат тест урьдчилан бодсон зүйлийг л шалгадаг бол exploratory тест хэн ч бодоогүй согогийг олдог тул хоёулаа хэрэгтэй гэж дүгнэлээ.
