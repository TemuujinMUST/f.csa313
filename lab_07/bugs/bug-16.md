# BUG-16: POST /api/books руу буруу JSON илгээхэд 400 биш «200 OK» ба {"result":"OK"} буцаадаг

Орчин:  Уншлагын жагсаалт v2.0, Chrome v155.0.8059.80, macOS Tahoe 26.6, 2026-10-20
Урьдчилсан нөхцөл: node app.js-ийг шинээр асаасан (анхны 3 ном)

## Дахин гаргах алхам

1. Терминалд дараах командыг ажиллуул:
```
   curl -i -X POST localhost:3000/api/books -d 'буруу оролт'
```
2. Гаралтын эхний мөр (статус) ба биеийг хар.
3. Ном нэмэгдсэн эсэхийг шалга:
```
   curl -i localhost:3000/api/books
```

Хүлээгдэж байсан: Спецификацийн дүрэм «API: буруу JSON биетэй POST хүсэлтэд 400 алдаа буцаана.» Алхам 1-д `HTTP/1.1 400 Bad Request` ба алдааны тайлбар буцах ёстой.

Бодит үр дүн:     Алхам 1-д `HTTP/1.1 200 OK`, бие нь `{"result":"OK"}`. Алхам 3-т жагсаалт өөрчлөгдөөгүй (3 ном), өөрөөр хэлбэл API амжилттай гэж хариулсан ч ном хадгалагдаагүй.

Ноцтой байдал: Major. API-г ашигладаг клиент (frontend, гуравдагч систем) алдааг илрүүлэх боломжгүй. Хүсэлт амжилттай гэж хариулсан ч өгөгдөл хадгалагдаагүй тул чимээгүй өгөгдөл алдагдал үүсгэнэ. HTTP статусын гэрээ зөрчигдсөн.
