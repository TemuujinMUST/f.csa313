# BUG-01: Ном нэмэх формд талбаруудыг хоосон орхиход ном нэмэгдэж, «Ном нэмэгдлээ» мессеж гардаг

Орчин:  Уншлагын жагсаалт v2.0, Chrome v155.0.8059.80, macOS Tahoe 26.6, 2026-10-20
Урьдчилсан нөхцөл: node app.js-ийг шинээр асаасан (анхны 3 ном)

## Дахин гаргах алхам

1. Браузерт `http://localhost:3000` хуудсыг нээ. Хүснэгтэд 3 ном харагдана.
2. «Гарчиг», «Зохиолч», «Он» гурван талбарыг бүгдийг нь хоосон орхи.
3. «Нэмэх» товчийг дар.

Хүлээгдэж байсан: Спецификацийн дүрэм «Ном нэмэхэд Гарчиг, Зохиолч, Он гурван талбар бүгд заавал бөглөгдсөн байх ёстой; дутуу бол ном нэмэгдэхгүй, ойлгомжтой алдааны мессеж харагдана.» Ном нэмэгдэхгүй, алдааны мессеж харагдах ёстой.

Бодит үр дүн:     «Ном нэмэгдлээ» мессеж гарч, хүснэгтэд 4 дэх мөр нэмэгдсэн: Гарчиг ба Зохиолч хоосон, Он нь «0». Алдааны мессеж харагдахгүй.

Ижил шалтгааны хувилбарууд (нэг согогт нэгтгэв):
- Зөвхөн «Гарчиг»-т `Test` бичээд нэмэхэд: Гарчиг «Test», Зохиолч хоосон, Он «0» мөр нэмэгдэнэ (bug-02.png).
- Зөвхөн «Зохиолч»-д `Test` бичээд нэмэхэд: Зохиолч «Test», бусад хоосон мөр нэмэгдэнэ (bug-03.png).
- Зөвхөн «Он»-д `Test` бичээд нэмэхэд: Гарчиг, Зохиолч хоосон, Он «NaN» мөр нэмэгдэнэ (bug-04.png).
- API түвшинд: `curl -i -X POST localhost:3000/api/books -H 'Content-Type: application/json' -d '{"title":"Only title"}'` нь `HTTP/1.1 201 Created` буцааж, номыг хүлээн авдаг (evidence/bug-17-curl.txt; session-ий үед өмнө нь ном нэмсэн тул `id` нь 5, шинээр асаасан аппад 4 гарна).

Ноцтой байдал: Major. Заавал талбарын дүрэм UI ба API хоёр түвшинд хоёуланд нь хэрэгжээгүй тул утгагүй, хоосон бичлэгүүд жагсаалтад хуримтлагдана. Амжилтын мессеж хэрэглэгчийг төөрөгдүүлнэ. Апп унахгүй, буруу мөрийг гараар устгаж болох тул Critical биш.
