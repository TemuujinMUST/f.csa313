# Charter

- **Судлах:**   Уншлагын жагсаалт аппын ном нэмэх, хайх, устгах функц, «Нийт ном» тоолуур, хуудасны текст ба линкүүд, /api/books API-г

- **Ашиглан:**  хоосон талбар, хэт урт ба тусгай тэмдэгттэй оролт, хязгаарын онууд (999, 1000, 2100, 2101, бутархай, үсэг), давхардсан ном, кирилл/латин ба том/жижиг үсэг хольсон хайлтын үг, curl-ээр илгээсэн буруу JSON-г

- **Илрүүлэх:** validation-ий цоорхой, үйлдэлд тохирохгүй мессеж ба үсгийн алдаа, хүснэгт ба тоолуурын өгөгдлийн зөрүү, API-ийн буруу статус код, ажиллахгүй хуудас, линкийг

## Сонгосон аялалууд

- **Couch Potato (Зочид буудлын дүүрэг):** Талбаруудыг хоосон эсвэл дутуу орхиод «Нэмэх», «Хайх» дарна. Спецификацид гурван талбар бүгд заавал бөглөгдсөн байх ёстой гэсэн тул хоосон оролтыг боловсруулах нь энэ аппын эхний эрсдэл гэж үзсэн.
- **Supermodel (Жуулчны дүүрэг):** Функцийг орхиод зөвхөн харагдах байдлыг (текст, мессеж, товчны өнгө, урт оролттой хүснэгт, линкүүд) шалгана. Аппын UI цөөн дэлгэцтэй тул текст бүрийг удаан уншиж typo, тохиромжгүй мессеж хайхад тохиромжтой.
- **Fed-Ex (Бизнес дүүрэг):** Нэг номыг нэмэх → хүснэгт → хайлт → «Нийт ном» тоолуур → устгах замаар мөшгиж, өгөгдөл алхам бүрт зөв үлдэж байгааг шалгана. Спецификацид тоолуур хүснэгттэй тэнцүү байх ёстой гэсэн тул өгөгдлийн замыг мөшгөх нь чухал.
- **Saboteur (Бүдүүлэг дүүрэг):** curl-ээр /api/books руу эвдэрсэн JSON, дутуу талбартай хүсэлт илгээж, статус кодыг `-i`-ээр шалгана. Хэрэглэгчийн интерфейсээр хийж болохгүй довтолгоог API түвшинд туршиж, UI-ийн бус согог олох боломжтой.
